# Politique de sécurité

## Signaler une vulnérabilité

Si vous découvrez une faille de sécurité dans ReadingTK (application web, extensions navigateur ou application Windows), merci de **ne pas** ouvrir d'issue publique.

Contactez-nous directement à **contact@tkissdev.com** en décrivant :

- La nature de la vulnérabilité
- Les étapes pour la reproduire
- L'impact potentiel

Nous nous engageons à répondre sous 72 heures et à corriger les failles confirmées dans les meilleurs délais.

## Périmètre

- Application web ([readingtk.net](https://readingtk.net))
- Extensions navigateur (Chrome, Firefox)
- Application Windows

Merci de votre aide pour garder ReadingTK sûr pour tous ses utilisateurs.
